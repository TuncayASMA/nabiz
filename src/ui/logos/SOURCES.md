# Marka logoları

Marka işaretleri yeniden çizilmedi; Lobe Icons'un aşağıdaki SVG dosyaları aynen alındı. Tek renkli işaretler koyu arayüzde CSS ile beyaz gösterilir. Claude ve Gemini'nin renkli dosyaları kullanılır. Logolar ilgili marka sahiplerine aittir; yalnızca takip edilen servisi tanımlamak için gösterilir.

Kaynak: https://github.com/lobehub/lobe-icons
Sabit sürüm: `a701c41c591947221bde9613c7dc6a6f49b600d4`
Kaynak dizini: `packages/static-svg/icons/`

- `claude-color.svg`: Claude
- `openai.svg`: ChatGPT/OpenAI
- `gemini-color.svg`: Google Gemini (Argon bu kartın içindeki model havuzudur)
- `grok.svg`: Grok
- `elevenlabs.svg`: ElevenLabs

Kaynak projenin lisansı aynı dizindeki `LICENSE` dosyasında korunmuştur. Bu dosyalar uygulamayla paketlenir; çalışma sırasında CDN isteği yapılmaz.
